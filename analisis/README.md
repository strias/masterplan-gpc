# Análisis

Análisis temáticos que integran fuentes y afirmaciones. Un archivo por tema:

- `financiero.md`: inversión, financiamiento, retorno y riesgo para el club
- `urbano.md`: impacto en el barrio, tránsito, normativa urbana
- `deportivo.md`: capacidad, estándares, uso del estadio
- `legal.md`: permisos, contratos, gobernanza y aprobación por los socios
- `social.md`: socios, vecinos, identidad y patrimonio

Se crean a medida que haya material.
